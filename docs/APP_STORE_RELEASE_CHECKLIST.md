# App Store Release Checklist

- [ ] Confirm marketing version and build number match the Finder extension.
- [ ] Verify signing team, nested extension bundle ID, App Group, and Keychain behavior.
- [ ] Verify App Sandbox, incoming/outgoing network, scoped bookmark, and user-selected file access.
- [ ] Confirm Bonjour declaration and local-network usage description.
- [ ] Assign every AppIcon slot and prepare screenshots.
- [ ] Review English and Turkish localization.
- [ ] Confirm Debug localhost controls and insecure transport are unavailable in Release.
- [ ] Add final privacy policy, support URL, and marketing URL.
- [ ] Archive, validate, and perform App Store/notarization checks.
- [ ] Test two Macs, sleep/wake, network changes, offline conflicts, large files, migration, clean install, and update from the previous version.
