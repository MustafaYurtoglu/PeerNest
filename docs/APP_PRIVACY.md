# PeerNest Privacy Foundation

PeerNest transfers selected folder contents directly between devices on the same local network. It has no PeerNest account, advertising SDK, analytics SDK, or central file server. Folder metadata and file content are sent only to a paired peer selected by the user. Trusted-device identities are stored locally, cryptographic private keys use Keychain, and recovery versions and trash remain local.

Diagnostics export is user-initiated and contains counts, versions, sanitized state, and capability summaries. It excludes file contents, private keys, session keys, raw bookmarks, full paths, and raw trusted-peer public keys.

App Store privacy-label answers must be reviewed manually against the shipping binary, Apple crash-reporting choices, support workflow, and final privacy policy. The current repository does not intentionally transmit analytics or advertising data to the developer.
