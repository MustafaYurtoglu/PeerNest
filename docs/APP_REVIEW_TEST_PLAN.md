# App Review Test Plan

1. Launch PeerNest and complete or skip onboarding.
2. Add a temporary folder and confirm local activity monitoring.
3. On a second Mac running the same signed build, grant local-network access, discover, pair, and explicitly accept a share invitation.
4. Create and edit sample files on both Macs; confirm encrypted local transfer and recovery UI.
5. Enable the Finder extension in System Settings and use its contextual menu.

One Mac can demonstrate onboarding, folder management, monitoring, settings, and recovery UI, but cannot prove peer synchronization. There are no fake peers, review credentials, security bypasses, or Release demo backdoors.
